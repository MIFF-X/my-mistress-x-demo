# Dashboard Styles

Canonical browser-era dashboard style and role-switch helpers live here.

## Files

- `dashboard.css` - dashboard page, sidebar, card grid, modal, and responsive styles.
- `dashboard-role-picker.js` - clean Mistress/Sub role picker used by login and old browser screens.
- `dashboard-shell.js` - small shell helper for legacy dashboard modules.
- `header.js` and `sidebar.js` - legacy dashboard helper modules.

Use `frontend/styles/dashboard/*` for new dashboard-style imports. The older
`frontend/styles/dashboards/*` path is compatibility-only while legacy imports
are migrated.
