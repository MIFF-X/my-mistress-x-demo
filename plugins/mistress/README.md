# Mistress Plugins

Canonical plugin bucket for Mistress-owned creator tools, live tools,
monetization add-ons, punishment controls, and optional dashboard extensions.

Migrated buckets include:

- `blogger-manager/`
- `auction-system/`
- `ppv-content/`
- `punishment-system/`
- `wheel-misfortune/`

Older compatibility files under `frontend/features/plugins/mistress/` should
stay as thin re-exports until bridge imports are fully retired.
