# Shared Suggestions Plugin Bucket

This bucket holds frontend helpers for suggestion intake and lightweight
feedback forms. Backend moderation, voting, rewards, and notification delivery
belong in their own feature contracts.

## Modules

- `suggestions.js` - suggestion creation, status updates, and summaries.
- `feedback-form.js` - form definition, validation, and response helpers.

## Status

The bucket is conflict-marker clean and import-safe for bridge usage.
