# After-Live Bookings

Canonical shared communication helpers for after-live booking dashboards,
sync panels, receipts, bridge-session summaries, and Sub/Mistress booking
lists.

The old `frontend/features/plugins/shared/communication-system/after-live-*`
compatibility re-export shims were removed after the smoke script and role
screens moved to canonical imports. New role screens should import from this
folder.
