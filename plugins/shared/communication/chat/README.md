# Shared Communication / Chat Plugin

This is the canonical chat plugin bucket. The old feature-layer bridge files
under `frontend/features/plugins/shared/communication/chat` were removed after
active imports moved to canonical shared communication paths.

## Modules

- `chat-screen.js`
- `chat-list.js`
- `chat-window.js`
- `chat-input.js`
- `chat-store.js`
- `chat.css`

## Snapshot

The bucket provides import-safe chat UI building blocks, local conversation
state, paid-unlock helpers, and compatibility hooks for older feature routes.
