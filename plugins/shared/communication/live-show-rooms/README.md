# Shared Live Show Rooms

Canonical browser-era live room helpers for room lobby access, Watch With Mistress, live offer trays, after-show availability, and after-show private-message request review.

The old room/watch/offer shims under `frontend/features/plugins/shared/communication-system/live-shows` were removed after the bridge usage audit found zero active callers for those helpers. The remaining live-show bridge folder only covers the older live hub, discovery, setup, and launch scaffold until that bucket is migrated separately.
