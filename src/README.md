# Frontend Source

This folder contains source code for the frontend app branch.

## Main areas

```text
api/        API clients and request helpers
features/   Feature screens, flows, and UI modules
```

## Folder rules

```text
1. API clients belong in frontend/src/api.
2. Feature UI belongs in frontend/src/features/<feature-name>.
3. Each major feature folder should include a README.md.
4. README files should use the Mistress-X inspired animated header template.
```
