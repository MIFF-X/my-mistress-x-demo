# Frontend Features

This folder contains frontend feature modules for the Mistress-X app branch.

## Current documented feature folders

```text
admin/          Headmistress/Admin Command Centre
ai-team/        AI provider team switcher, routing policy and usage analytics
bookings/       Paid calls and booking lifecycle
content-library/ Media libraries, playlists, drop calendars, packs and archive rules
games/          Quiz imports, hosted games, reaction rooms and live overlays
marketplace/    Inventory plugins, marketplace worlds, Private Vault
money/          Earnings Vault creator cashout and payout request flow
preview-ops/    Local preview tunnels, readiness checks and shutdown safety
rolodex/        Mistress Rolodex + Sub-side Little Black Book mirror
sub-vault/      Consent-first Sub Vault / Verification Vault scaffold
stickers/       Sticker Studio, sticker packs, collector albums
workshop/       Workshop moderation portal, release pages and OAuth links
```

## Feature README checklist

Each major feature README should document:

```text
purpose
primary screens/components
connected frontend API clients
connected backend routes/modules
role and permission rules
wallet/source-of-truth rules
Command Centre links
local verification checklist
future polish list
```
