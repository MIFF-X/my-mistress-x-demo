# Styling Pack Assets

Styling packs are installable visual bundles for Mistress profiles, House themes, badges, cards, and marketplace add-ons.

## Pack categories

```text
free icon packs
paid icon packs
custom icon packs
free font packs
paid font packs
custom font packs
seal packs
stamp packs
logo packs
badge packs
card frame packs
dashboard action button packs
action-row button packs
House theme packs
favicon packs
animated GIF deck packs
```

## Marketplace flow

```text
Contributor submits pack
Headmistress reviews pack
Approved pack is listed
Mistress installs or purchases pack
Pack changes profile/dashboard visual style
```
